How to Publish This Web App for Free

  1. Create a free account at GitHub.com.
  2. Create a new public repository named prayers-weaver.
  3. Save this file on your computer as index.html.
  4. Upload index.html into your new GitHub repository.
  5. Go to Settings > Pages in your repository.
  6. Under Branch, select main and click Save.
  7. In 60 seconds, GitHub will give you a live shareable URL (e.g. https://yourname.github.io/prayers-weaver/)!
